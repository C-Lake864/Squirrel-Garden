# 🐿️ 도토리 할 일 (iffel_todo-list)

내 컴퓨터에서 도는 Todo 앱. 오늘 할 일을 다 끝내면 다람쥐가 알밤을 묻고,
한 달 동안 모은 알밤 수에 따라 나무가 자랍니다.

## 자라는 단계 (이번 달 알밤 수 기준)
| 알밤 | 단계 |
|---|---|
| 5개 | 새싹 |
| 10개 | 묘목 |
| 15개 | 작은 나무 |
| 20개 | 큰 나무 |
| 25개 이상 | 무척 큰 나무 |

## 실행 방법
```bash
npm install     # 최초 1회 (express, dotenv 설치 — DB는 내장이라 설치 없음)
npm start       # 서버 실행
```
그다음 브라우저에서 **http://localhost:3000** 접속.

## 기능
- 할 일 추가 / 목록 / 완료 표시 / 삭제 (기본 CRUD)
- 마감일 표시 (오늘/지난 마감 색으로 구분)
- 카테고리(태그)
- "오늘 할 일"만 보기 / 전체 보기
- **대충하기**: 부담스러운 할 일을 더 작은 문장으로 바꾸기 (원래 문장은 보관, "원래대로"로 되돌리기)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `server.js` | 서버 + API (추가/완료/삭제/대충하기/정원 상태) |
| `db.js` / `schema.sql` | DB 연결과 테이블 정의 |
| `public/index.html` `style.css` `app.js` | 화면 |
| `.env` | 설정값(포트, DB 파일 경로) — 코드에 안 넣고 여기 둠 |

## 규칙 반영
- **무료 도구만**: Node.js 내장 SQLite + Express(오픈소스)
- **설정은 `.env`로 분리**, `.gitignore`로 `.env`·`*.db` 커밋 차단
- 모든 DB 접근은 `?` **파라미터화 쿼리** (SQL 인젝션 방어)
- 로그인은 넣지 않음(1인 로컬 앱). 필요해지면 직접 만들지 말고 검증된 라이브러리 사용

## 알밤 규칙 (참고)
"마감일이 오늘"인 할 일을 **전부 완료**하면 그날 알밤 1개가 쌓입니다.
마감일 없는 할 일은 알밤에 영향을 주지 않아요(언제든 하는 일).

이 저장소는 김채원이 Cloud Run 배포 실습용으로 만들었다.
